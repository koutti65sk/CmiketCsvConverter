# Excel CSV Converter

Excelファイルから指定された形式のCSVファイルへ変換するツールです。

複数のシートをまとめて処理し、必要に応じてCSVをZIPファイルへ圧縮できます。

---

## 主な機能

* Excelファイル（`.xlsx`）の読み込み
* 複数シートの一括変換
* Excel内のハイパーリンク取得
* CSV形式への変換
* CSVファイルのZIP圧縮
* 保存先フォルダの指定
* 前回使用した保存先の記憶
* 保存する名前の指定
* 前回使用した保存名の記憶
* 読み込み方法の変更
* 読み込み行数の指定
* 既存ファイルの上書き確認
* 変換処理のキャンセル
* 変換進捗の表示
* 変換ログの表示

## 使い方

### 1. Excelファイルを選択

「Excelを選択」ボタンから変換するExcelファイルを選択します。

### 2. 保存先を指定

「保存先を選択」からCSV・ZIPファイルの保存先を指定できます。

保存先を指定しない場合は、元のExcelファイルと同じフォルダに保存されます。

一度指定した保存先は次回起動時にも使用されます。

「元に戻す」を押すと、Excelファイルと同じフォルダに保存する設定へ戻ります。

### 3. 保存する名前を指定

「保存する名前」に任意の名前を入力できます。

指定しない場合は、元のExcelファイル名が使用されます。

指定した保存名は次回起動時にも保持されます。

### 4. 変換設定

#### 購入内容が空白まで

「購入内容」列が空白になったところで、そのシートの読み込みを終了します。

#### 指定行まで

指定した行数までExcelを読み込みます。

### 5. ZIPファイル

「ZIPファイルを作成する」にチェックを入れると、作成したCSVをZIP形式に圧縮します。

ZIP作成時は、元のCSVファイルは削除されます。

## 出力ファイル

通常は以下の形式で出力されます。

```text
保存先/
├── ファイル名_シート名.zip
└── ...
```

ZIPを作成しない場合：

```text
保存先/
├── ファイル名_シート名.csv
└── ...
```

ZIPファイルの中には、Caicoが保存データとして認識する固定名
`list.csv` でCSVファイルが1つ入ります。

    ファイル名_シート名.zip
    └── list.csv

CSVをZIP内でも元のファイル名のまま保存すると、Caico側で
「Caicoデータが含まれていない」と判定されるため、ZIP内の名前は変更しないでください。

---

## 上書きについて

同じ名前のCSVまたはZIPファイルがすでに存在する場合、上書き確認が表示されます。

選択できる操作：

* **はい**：既存ファイルを上書きして変換
* **いいえ**：そのシートをスキップ
* **キャンセル**：変換処理をキャンセル

---

## キャンセルについて

変換中に「変換をキャンセル」ボタンを押すと、処理のキャンセルを要求します。

すでに完了したシートの出力結果はそのまま残ります。

---

## 設定

「設定」から以下の項目を変更できます。

* デフォルトの読み込み方法
* デフォルトの読み込み行数
* ZIPファイルを作成するかどうか

設定は `settings.json` に保存されます。

## 注意事項

* Excelファイルの列名が想定されている形式と異なる場合、正常に変換できない場合があります。
* Excelファイルはバックアップを取ってから使用することを推奨します。
* 既存のCSV・ZIPファイルを上書きする場合は注意してください。
* `settings.json` にはアプリの設定情報が保存されます。
